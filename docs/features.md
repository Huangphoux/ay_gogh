
# Features

- Write the texts in Markdown, so that those can be downloaded as EPUB
- Determine words that are not in the NGSL beforehand.
- Determine CEFR level of a word beforehand.
- PWA, can handle being offline
- Lightweight, fast on mobile and 3G (most important!!!)
- recordTrimEdit: record chapter audio
- No comments: nobody got time to moderate that, also people could talking in non-English
- i18n, l10n vs. Full-on English ?
- Last modified time
- a11y
